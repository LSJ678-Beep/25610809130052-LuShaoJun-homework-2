## 玩法
- **WASD** 移动，**鼠标左键** 挥杖施法（按住连发），**空格** 冲刺闪避，**Esc** 暂停
- 击杀魔物拾取经验，升级三选一强化（奥能强化 / 疾风施法 / 分裂魔弹 / 伴飞精灵……）
- 魔法森林草地场景，一昼夜 140 秒循环：白天→黄昏→星空萤火，角色与魔物随昼夜有自发光变化
- 每 5 级出现森林巨魔 BOSS

## 文件
- `index.html` —— 全部游戏逻辑（单文件，无构建）
- `libs/three.global.js` —— three.js r160 全局版（离线可用）

浏览器打开 `index.html` 即可运行（需 `libs/` 同目录）。

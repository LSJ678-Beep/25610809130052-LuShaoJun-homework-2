# 秘林魔潮 · 3D 打怪升级

互动编程 作业二（互动艺术与电子媒介）作品源码。

在线试玩：<https://lsj678-beep.github.io/interstellar-swarm/>

## 玩法
- **WASD** 移动，**鼠标左键** 挥杖施法（按住连发），**空格** 冲刺闪避，**Esc** 暂停
- 击杀魔物拾取经验，升级后三选一强化（奥能强化 / 疾风施法 / 分裂魔弹 / 伴飞精灵……）
- 场景为魔法森林草地，一昼夜 140 秒循环：白天→黄昏→星空与萤火
- 每 5 级出现森林巨魔 BOSS

## 文件
- `index.html` —— 全部游戏逻辑（单文件，无构建）
- `libs/three.global.js` —— three.js r160 全局版（离线可用）

直接用浏览器打开 `index.html` 即可运行（需 `libs/` 同目录）。
